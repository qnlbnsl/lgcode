# Roadmap

Shephrd is meant to make it possible for anyone to run a Herdr server,
install Shephrd, and set up and steer teams of coding agents from a phone,
with every agent's conversation available as a thread.

## Now

| Kind | Name | Overview |
|---|---|---|
| epic | shepherd-foundation | The pieces that let Shephrd run the Foundry's teams on its own: the engine, the client API, the message board, and the foundry roles. The engine is built, and the plans for the other three are accepted and ready to build. A fifth plan, Git worktrees for agents, is next to be written. |

## Later

| Kind | Name | Overview |
|---|---|---|
| other | Interactive mode | Running a harness's normal terminal program in a Herdr pane, behind the same delivery interface, for harnesses where that is cheaper, such as Claude Code. |
| other | Desktop and phone apps | Native apps on the client API, after the web page and the Herdr-pane thread viewer. |
| other | A Visual Studio Code extension | Threads and approvals in a side panel of Cursor or Visual Studio Code, as a client of the same API. |
